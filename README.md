# 오늘, 사진

에펠탑과 자전거가 보이는 파리 배경 위에 카메라 인물을 합성해 4:5 인생사진을 만드는
브라우저 포토부스입니다.

## 실행

```bash
npm run dev
```

실행 후 터미널에 표시되는 Local URL을 열고 카메라 권한을 허용하세요. 카메라 대신 기기의
사진을 불러와 합성할 수도 있습니다.

## 기능

- 노트북·USB·캡처카드 등 브라우저가 인식하는 카메라 선택 및 실시간 촬영
- 카메라 연결·해제 감지와 기본 카메라 자동 복구
- 지원 카메라에서는 `ImageCapture` 센서 정지사진을 우선 사용하고, 미지원 장치는 연속 프레임 중
  얼굴 영역이 가장 선명한 장면을 선택
- 사진 불러오기
- MediaPipe 기반 AI 인물 분리와 네트워크 실패 시 소프트 마스크 대체
- 촬영 원본과 정밀 인물 마스크를 고정한 뒤 배경을 적용하는 후처리 방식
- 촬영 후 배경 10종과 사용자 배경, 헤어 무드 4종, 선명·내추럴·필름·흑백 스타일 편집
- 얼굴 보호 영역을 유지하는 헤어 무드 합성과 얼굴 디테일 보정
- 파리 배경 톤, 인생사진 필터, 3초·5초 타이머
- 1440×1800 JPEG 저장
- 최종 스타일 확정 후 Google Drive에 완성본 한 번만 저장
- Web Share API로 카카오톡·메일·문자 앱 공유
- 이메일·휴대폰 번호를 넣어 작성 앱 바로 열기

입력한 이메일과 휴대폰 번호는 서버에 저장하지 않습니다. 완성 버튼을 누른 사진만 연결된
Google Drive 폴더로 전송됩니다. AI 인물 분리 모듈은 최초 실행 시 인터넷 연결이 필요합니다.

헤어 기능은 얼굴 자체를 생성하거나 바꾸지 않고, 촬영한 얼굴과 헤어 경계를 보존한 상태에서
실루엣을 더하는 자연스러운 무드 프리셋입니다.

GoPro는 블루투스만으로 브라우저 영상 장치가 되지 않습니다. GoPro의 USB 웹캠 모드 또는
HDMI 캡처카드로 운영체제에 카메라로 등록한 뒤 화면의 `다시 찾기`를 누르면 선택할 수 있습니다.
