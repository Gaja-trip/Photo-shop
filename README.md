# 오늘, 파리

에펠탑과 자전거가 보이는 파리 배경 위에 카메라 인물을 합성해 4:5 인생사진을 만드는
브라우저 포토부스입니다.

## 실행

```bash
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 열고 카메라 권한을 허용하세요. 카메라 대신 기기의
사진을 불러와 합성할 수도 있습니다.

## 기능

- 실시간 카메라 촬영 또는 사진 불러오기
- MediaPipe 기반 AI 인물 분리와 네트워크 실패 시 소프트 마스크 대체
- 파리 배경 톤, 인생사진 필터, 3초·5초 타이머
- 1080×1350 JPEG 저장
- Web Share API로 카카오톡·메일·문자 앱 공유
- 이메일·휴대폰 번호를 넣어 작성 앱 바로 열기

사진과 입력한 연락처는 서버에 저장하지 않습니다. AI 인물 분리 모듈은 최초 실행 시 인터넷
연결이 필요합니다.
